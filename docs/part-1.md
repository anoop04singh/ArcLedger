- [x] ChainAccountingAdapter and Arc implementation.
- [x] Exact normalization, canonical native movements, one-to-one matching, receipt fees.
- [x] PostgreSQL schema and atomic finalized-block checkpointing.
- [x] viem finalized-block ingestion worker with chain guard and single-writer lock.
- [x] Read-only address, transaction explain, and status API.
- [x] Search, address, transaction, and status UI using the provided visual direction.
- [x] Explicit local demo and Mainnet modes, environment example, local Compose service.
- [x] Architecture, normalization, API documentation and Node client example.
- [ ] Mainnet end-to-end validation with live data and full balance reconciliation (later build stage).

Part 1 supplies working foundation code, not a claim that all five parts of the MVP are complete.
